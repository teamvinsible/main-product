# SEO Audit

## On-page
- Unique `<title>` and meta description per route (50–60 / 150–160 chars).
- One H1 per page; logical heading hierarchy.
- Canonical URLs and `robots` meta where needed.

## Technical
- `sitemap.xml` and `robots.txt` reachable.
- Core Web Vitals: avoid render-blocking assets, size images, lazy-load below fold.
- Mobile-friendly viewport and tap targets.

## Content
- Target keyword in title, H1, first paragraph naturally.
- Internal links between related pages.
- Alt text on images.

## Deliverable
- Write findings to `_artifacts/marketing/seo-audit.md` with prioritized fixes.
